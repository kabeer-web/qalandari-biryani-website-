# Qalandari Biryani Food Center

React + Vite + Tailwind CSS food ordering site with WhatsApp checkout.

## Run
    npm install
    npm run dev

## Edit
- Menu & prices: src/data/menu.js
- WhatsApp number, name, tagline, delivery fee: src/config.js
- Own photos: put files in public/images and set image: "/images/name.jpg" in menu.js

## Deploy
    npm run build   # output in /dist
